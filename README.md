
# 📊 DataViz Pro – Interactive Data Visualization Dashboard

### Transform Your Data into Meaningful Insights!

## 🚀 About the Project

**DataViz Pro** is an interactive, web-based data visualization and analytics dashboard designed to simplify the process of exploring and understanding datasets.

The application allows users to upload datasets in different file formats and explore their data through an interactive analytics dashboard.

With a modern user interface and easy-to-use functionality, DataViz Pro aims to make data exploration more accessible and efficient.

## ✨ Key Features

* 📁 **Multiple File Uploads:** Upload datasets using Drag & Drop or Browse Files.
* 📊 **Multiple File Formats:** Supports CSV, Excel (.xlsx, .xls), JSON, and TSV files.
* 📈 **Interactive Analytics:** Explore datasets through interactive visualizations.
* ⚡ **Quick Data Exploration:** Easily upload and explore datasets.
* 🎨 **Modern UI:** Clean, responsive, dark-themed dashboard interface.
* 📂 **Sample Dataset:** Includes a sample sales dataset for demonstration.
* 🖥️ **User-Friendly Interface:** Simple navigation and easy dataset uploading.

## 🛠️ Technologies Used

* **HTML5** – Application structure.
* **CSS3** – Styling and user interface design.

## 💻 Getting Started

Follow these steps to run DataViz Pro on your local machine.

### Prerequisites

* A modern web browser (Chrome, Edge, or Firefox).
* Visual Studio Code (optional).

### Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/DataViz-Pro.git
```

**Step 2: Navigate to the project directory**

```bash
cd DataViz-Pro
```

**Step 3: Run the application**

Open the HTML file in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
